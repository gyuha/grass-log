# grass-log

GitHub 활동을 매일 자동으로 수집해 하루치 로그 파일로 남기는 개인 리포지토리. 부수 효과로 기여 그래프(잔디)가 유지된다.

## Language

**잔디**:
GitHub 프로필의 기여 그래프(contribution graph)에 표시되는 초록 칸. 이 프로젝트에서 잔디는 목적이 아니라 로그 커밋의 부수 효과다.
_Avoid_: 커밋 그래프, 히트맵

**하루**:
로그 파일 하나가 담당하는 시간 범위. GitHub 프로필 타임존이 정하는 하루와 동일하게 정의한다 — UTC 하루가 아니다. [[ADR-260822-093205]]
_Avoid_: 날짜, 일자

**일일 로그**:
`logs/YYYY/MM/YYYY-MM-DD.md` 하나. 그 하루의 GitHub 활동(커밋·PR·이슈·리뷰)을 YAML 프론트매터 + 마크다운 본문으로 담는다. 활동이 없는 날에도, 수집이 실패한 날에도 같은 경로에 같은 형식으로 생성된다.
_Avoid_: 데일리 리포트, 일지

**활동 없음**:
그 하루에 GitHub 기여가 0건이었다는 사실. 수집이 성공했고 결과가 비었다는 뜻이며, 수집 실패와 엄격히 구분된다.
_Avoid_: 빈 날, 공백

**수집 실패**:
GitHub API 조회가 에러로 끝나 그 하루의 활동을 알 수 없는 상태. 이 경우에도 실패 사실을 적은 로그 파일을 커밋한다 — 잔디를 끊지 않고, 실패를 기록에 남기기 위해서다.
_Avoid_: 에러, 장애

**그래프 카운트**:
`contributionCalendar.contributionDays[].contributionCount` — 잔디 그래프에 실제로 표시되는 그날의 기여 수. 로그의 프론트매터에 기록해, 로그 자신이 "잔디가 실제로 심겼는가"에 답하게 한다.
_Avoid_: 기여 수, 컨트리뷰션

**불일치**:
그래프 카운트 기준 커밋 수와, 리포별 default branch 히스토리에서 목록화한 커밋 수가 다른 상태. default branch 외 커밋이나 타임존 경계 추론 오류를 드러내는 신호이므로 로그 본문에 명시 기록한다.
_Avoid_: 오차, 갭
